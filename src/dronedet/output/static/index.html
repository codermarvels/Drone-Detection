Gain

    
Lower the LNA gain if a strong nearby signal (like your own Wi-Fi router) makes everything look loud; raise it for distant drones. Saving restarts the detector with the new gain. Each recording session stores the gain it was made with.

    

      
      
      
      

    

    
The RF amplifier is for weak, distant signals only. A strong signal close to the antenna with the amplifier on can damage the HackRF's front end.

    
Calibration

    
Takes 100 sweeps and reports the noise floor and the strongest frequencies. Nearby Wi-Fi usually shows around 2412, 2437 or 2462 MHz. Run it after changing the gain, the antenna or the place.

    

    

  


  

    
Receiver location

    
Where the HackRF is. It centres the map.

    

      
      
      
      

    

    
Offline map

    
Downloads map tiles around the receiver once, so the map works offline afterwards. Needs internet for this step only. OpenStreetMap allows only small areas and may refuse; if it does, paste another provider's tile URL (many give a free key), or copy an MBTiles map file to data/map.mbtiles, which is used instead of downloaded tiles.
